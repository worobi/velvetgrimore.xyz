# Velvet Grimoire Intimate Table

The Intimate Table layer turns a scene into consent-aware in-character messaging.

## What it adds

- Scene-bound chat shared by the Warden and Protagonist views
- Message modes: Spoken, Action, Thought, Whisper, OOC Check-in
- Consent ceilings for each side
- Effective ceiling based on the lower selected level
- Heat / tension meter
- Prompt chips for keeping momentum
- Private want / boundary cards
- Compatibility summary
- Veil / Fade Out and Hearth buttons inside the scene

## How to use it

1. Start or load a campaign session.
2. Open Admin and Player View in separate tabs.
3. Enter the current scene from the Player View.
4. Each side sets a consent ceiling and saves a want / boundary card.
5. Use prompt chips or freeform lines to keep the exchange inside the game fiction.
6. Lower the ceiling, choose Veil / Fade Out, or open Hearth whenever needed.

## Current limitation

This version syncs through browser storage, so it works best for two tabs on the same browser or a shared browser session. Real remote multiplayer needs a shared backend.

## Authoring guidance

Keep prompts playable:

- Use in-character questions before escalation.
- Treat Fawn as tactical yielding, not automatic consent.
- Use OOC Check-in for any uncertainty.
- Let either side lower the ceiling immediately.
- Prefer fade-to-black when the scene has done its narrative work.
