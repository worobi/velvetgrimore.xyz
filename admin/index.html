The Crimson Veil Demo

Installs a complete starter campaign with 11 linked scenes, four branch paths, ward tags, six scene templates, a playable manor map, and sample Threshold/Hearth records for screenshots.

What the demo proves

A buyer can see campaign setup, ward enforcement, the player-facing scene gate, the map, dice, and Hearth closure without writing anything first.

What to customize

Replace names, ward choices, Banished Names, scene text, map events, and screenshots before using it for a private table.

What to package

Ship this folder with the root README, roadmap, demo walkthrough, Compact docs, and every file under engine, demo, dice, map, player, and admin.

Load or create a campaignUse the demo first, or create your own campaign from the Campaigns panel.

Per TAGS.md §II — these element wards are hard-gated. Tick only those the protagonist has explicitly consented to appear in scenes. Any scene using an unacked ward is refused at save time. You can revise this later by editing the campaign.
⛔ BANISHED NAMES
Protagonist-level hard limits. Any scene carrying one of these wards is refused at save time.
✦ HALLOWED GROUND
Content that may exist in lore but never appears on page. The default floor is always preserved.
🌫 VEILED GROUND
Content that can appear only impressionistically. Matching scenes are forced to suggested intensity.
