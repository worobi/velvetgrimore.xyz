# Velvet Grimoire Demo Walkthrough

Use this when showing the product to a buyer, testing a release, or capturing screenshots.

## 1. Load the demo

Open `index.html`, choose **Warden**, then click **Load Demo Campaign**. The installer adds:

- The Crimson Veil campaign
- 11 linked scenes
- Fight / Flight / Fawn / Freeze branches
- 6 reusable scene templates
- Ashfall Manor map
- Example Threshold and Hearth records

## 2. Capture the admin screenshots

Open `admin/`.

Good screenshot states:

- First Run panel with the demo banner visible
- Campaigns panel showing **The Crimson Veil**
- Scene Editor showing linked scenes and Fawn branch paths
- Scene modal with ward tags selected
- Active Session showing the current scene and all four branch buttons
- Intimate Table showing sample in-character messages, consent ceiling, heat, and want/boundary card controls
- Settings showing **Backup Everything**

## 3. Capture the player screenshots

Open `player/player.html`.

Good screenshot states:

- Warded Entry screen before the player enters a scene
- Live scene view with session summary, ward stack, narrative, cue, dice, and response notes
- Intimate Table with the prompt chips and shared chat log
- Hold signal active after using `pause.html#ember`

## 4. Capture the map screenshots

Open `map/dm-map.html` and select the demo map if needed.

Good screenshot states:

- Ashfall Manor Demo Map with zones and events visible
- Player map with fog of war and discovered tiles

## 5. Show the safety layer

Open `pause.html`.

Good screenshot states:

- Threshold tab with the demo example loaded
- Ember tab with Dim / Hold / Snuff visible
- Hearth tab with aftercare stations
- Compact tab as the readable safety index

## 6. Reset after screenshots

Use Admin -> Settings -> Backup Everything if you want to keep the current state.
Use Admin -> Settings -> Wipe All Data to remove campaigns while preserving Compact records.
